Project Overview:
    This project is a LibGDX game. It's a conceptually simple 4X strategy game for 3 players.

Game Overview:
    Victory: The Organism Game is a real time strategy game for three players. The board is a hexagonal grid and players spend energy to claim vertices with the organism they control. When no more moves can be made, the winner is the player with the most vertices captured.

    Energy: Players get a steady income of energy depending on the resources they control. Claiming a vertex has a fixed cost.

    Resources: There are three resource types arranged around the board with radial symmetry. Resources are associated with hexagons. Claiming all the vertexes of a hexagon claims that hex and all resources inside. The total number of resources owned has no direct effect. Being the leader in any one resource gives an energy bonus. If another player overtakes the leader, the bonus transfers to the new leader.

    For example. Let's say the resources look like this:

    player  resource 0  resource 1  resource 2
    0       5           2           1
    1       0           5           3
    2       1           1           1

    Player 0 leads in resource 0 and gets one bonus. Player 1 leads in resource 1 and 2, and gets 2 bonuses. Player 3 leads in nothing and gets base energy income.

    Tournament: The main game mode is a constant semi-random tournament. There is pool of participants greater than 3, let's say 20. 3 players are randomly selected to compete. They get a number of points at the end equivalent to the number of vertexes they captured.

    The overall tournament ranking is based on wins or the sum of all vertexes captured.

    After some number of rounds, the bottom players are eliminated and new players are introduced.

    There are currently three play modes, 1 player, 2 player and AI plays itself

    An escape menu allows the user to switch modes and start a new tournament

    Control interface: players manipulate a cursor in a circular area. a planchette follows the cursor at a slight delay. the planchette influences vertex selection so that the direction of growth is the direction of the planchette from the circle center

    Control interface cases: if the planchette is centered in the circle, growth with be unbiased in all directions. The player, human or AI, can move a cursor around the circular field. The planchette follows the cursor at a slight delay.

    AI: The AI idea is where this project is really interesting. It starts with the biological observation that vision is tightly coupled to cognition. The AI follows this loop:

    - select a hexagon on the map
    - the map is roughly circular, so the hex has a corresponding position in the control circle. move the cursor to that position
    - extract local information about the hexagon: position, resources, vertex ownership
    - use that info to select the next hex and repeat

    I want to implement some simple learning as well as an evolutionary component. The individual organisms should learn. When it's time to create new organisms, use values from the winners.
